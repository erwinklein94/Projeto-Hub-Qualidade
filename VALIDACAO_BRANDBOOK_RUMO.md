# Validação — Brandbook Rumo aplicado

Data da aplicação: 2026-05-29

## O que foi aplicado

- Tokens oficiais da Rumo centralizados nos CSS do hub, DM de Concreto e Subcomponentes.
- Paleta institucional ajustada para os HEX oficiais:
  - Azul: `#003865`
  - Azul claro: `#32A6E6`
  - Verde: `#1E9F7F`
  - Verde claro: `#7FE06C`
  - Amarelo: `#FBD300`
  - Laranja: `#F78344`
  - Cinzas de interface: `#F2F5F6`, `#E5EBEE`, `#D7E0E5`, `#CAD6DD`, `#BDCCD4`
- Azul Rumo mantido como cor dominante em fundos, navegação, botões e textos principais.
- Acentos em azul claro, verde e verde claro usados em barras, estados, gráficos e detalhes.
- Paleta secundária preservada apenas para alertas e destaques pontuais.
- Tipografia configurada como `"Cera Pro", Verdana, Geneva, Tahoma, sans-serif`.
- Nenhum arquivo de fonte Cera Pro foi embutido, respeitando a exigência de licença.
- Logos oficiais copiados para `assets/rumo/logos/` e aplicados no hub e nos painéis.
- Ícones oficiais copiados para `assets/rumo/icones/` para uso futuro/expansão visual.
- Componentes receberam bordas, sombras azuladas e chanfros/acabamentos sutis inspirados nos grafismos da marca.
- Cores dos gráficos do painel de Subcomponentes foram alinhadas à paleta oficial.
- Links do hub para DM de Concreto e Subcomponentes foram apontados para as páginas locais do pacote, para abrir as versões já modificadas.

## Observações

- A fonte Cera Pro é paga; o CSS apenas declara o nome para ambientes que já tenham a fonte licenciada/instalada. O fallback oficial Verdana fica ativo nos demais casos.
- O roxo da paleta secundária não foi usado, seguindo a orientação de uso mínimo.
- O favicon original do projeto foi preservado.
